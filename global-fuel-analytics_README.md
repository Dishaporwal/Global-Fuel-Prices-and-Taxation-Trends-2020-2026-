# Global Fuel Analytics website

A responsive static website with an editorial landing page, project overview, research questions, embedded Tableau dashboard, Tableau story, workflow, and conclusion.

## Run locally
Open `index.html` in a browser. An internet connection is required for the embedded Tableau views.

## Deploy
Upload `index.html` to any static host such as GitHub Pages, Netlify, or Render Static Site. Keep it at the site's root.

## Tableau embeds
The page uses the two Tableau Public views supplied by the user. If an embed does not load, confirm the workbook is published and publicly viewable in Tableau Public.
